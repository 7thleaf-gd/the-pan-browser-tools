安全設計

元ボタンを自動クリックしません。ページ内容・入力値・Secretを外部送信しません。外部API、GitHub Actions、Runner、定期処理も使いません。

Known Issues

SaaS側のUI変更でJA?が出ない場合があります。日本語化済みUI、iframe / Shadow DOM内の操作は未対応です。Windows/macOS版Chromeを主対象とし、Edge等は未検証です。

対応: GitHub 7操作 / Cloudflare 7操作 / Supabase 6操作。対応外操作にはJA?を表示しません。
