# PANDA DUB v0 loop kit

The bundled sounds are original procedural placeholders generated by
`scripts/generate-panda-dub-audio.py`.

- Tempo: 74 BPM
- Meter: 4/4
- Length: 4 bars
- Sample rate: 44.1 kHz
- Loop frame count: identical across `drums.wav`, `bass.wav`, `chord.wav`, and `voice.wav`
- Format: mono, 16-bit PCM WAV

To replace the loops, export every loop from the same timeline selection with
the same leading silence and exact duration. Leave headroom and do not normalize
individual stems to 0 dBFS. The three `shot-*.wav` files may have any length.
